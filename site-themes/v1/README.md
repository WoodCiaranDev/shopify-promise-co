# Prestige Theme v10.1.0 Documentation

## Overview

This is the **Prestige** theme version 10.1.0 by Maestrooo, a premium Shopify theme designed for luxury and high-end e-commerce stores. The theme emphasizes elegant design, customization flexibility, and performance optimization.

## Theme Structure

### Directory Layout

```
v1/
├── assets/              # CSS, JS, images, and static assets
├── config/              # Theme configuration and settings
├── layout/              # Main theme layouts
├── locales/             # Multi-language support (30+ languages)
├── sections/            # Reusable page sections
├── snippets/            # Reusable code fragments
└── templates/           # Page templates
```

### Key Features

#### 1. **Layout Options**
- Multiple header layouts (logo left, logo center, navigation below)
- Sticky header support
- Transparent header capability
- Customizable mega menus

#### 2. **E-commerce Features**
- Product quick view/buy functionality
- Advanced product galleries with zoom
- Variant pickers with color swatches
- Inventory tracking display
- Recently viewed products
- Related products suggestions
- Complementary products
- Product badges (sale, new, etc.)

#### 3. **Collection Features**
- Multiple collection page layouts
- Advanced filtering and sorting
- Collection-specific templates for different product categories:
  - Bestsellers
  - Color-based collections
  - Seasonal collections (High Summer, Winter)
  - Special collections (The Vault, Single Stones, Stacking Bands)

#### 4. **Content Sections**
- Hero slideshow
- Before/after image comparisons
- Image with text (multiple variations)
- Testimonials
- FAQ accordion
- Timeline
- Logo lists
- Multi-column content
- Newsletter signup (inline and popup)
- Countdown timers
- Video sections
- Blog posts grid
- Contact forms

#### 5. **Performance Optimizations**
- ES Module support with importmap
- Lazy loading for images
- Preconnect for fonts
- Minified vendor libraries
- CSS custom properties for theming

#### 6. **Customization Options**
- Color schemes system
- Typography controls (heading and body fonts)
- Icon stroke width adjustment
- Button and input border radius
- Section spacing controls
- Animation options (button transitions, image zoom, page transitions)

#### 7. **International Support**
- 30+ language translations including:
  - European languages (English, French, German, Spanish, Italian, etc.)
  - Asian languages (Japanese, Korean, Chinese Simplified/Traditional)
  - Middle Eastern languages (Arabic, Hebrew)
  - Nordic languages (Danish, Swedish, Norwegian, Finnish)

#### 8. **Advanced Features**
- Free shipping progress bar
- Shipping estimator
- Product ratings
- Social sharing
- Predictive search
- Cart drawer
- Privacy banner (GDPR compliance)
- Newsletter popup
- Social media integration

### Configuration Files

- `settings_schema.json` - Defines all customizable theme settings
- `settings_data.json` - Stores current theme configuration
- `markets.json` - Multi-market/currency configuration

### Technical Stack

- **Liquid** - Shopify's templating language
- **JavaScript** - ES6+ with module support
- **CSS** - Modern CSS with custom properties
- **SVG** - Scalable vector graphics for icons
- **JSON** - Configuration and localization data

### Performance Features

- Responsive images with proper srcset
- Critical CSS inlining
- Deferred JavaScript loading
- Font preloading
- Optimized third-party script loading

### Development Notes

- The theme uses Shopify's Online Store 2.0 architecture
- Section groups for header, footer, and overlay content
- Dynamic sections on all pages
- Extensive use of snippets for code reusability
- Well-structured localization with schema translations
